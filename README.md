# 📺 Multi-Streaming Service Monitor Bot

A lightweight Telegram bot designed for managing shared streaming platform profiles (Netflix, Disney+, Prime Video, HBO Max, etc.). Tracks assigned devices, customer slots, and automated rental expiration.

## 🚀 Features
* **Multi-Service Support:** Categorizes profiles by platform (Netflix, Disney+, etc.).
* **Admin Guarded:** Restricts control exclusively to the designated admin.
* **Auto Expiry Notifications:** Runs a background scanner to free profiles automatically and alert the owner on Telegram.
* **Inline Keyboards:** Fast menu navigation for standard commands.
